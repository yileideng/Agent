# 客户端接入指南

> 读者：需要接入 Agent 网关的外部客户端开发者
> 协议版本：CAP v0.1
> 快速接入：[2026-10-27-00-客户端快速接入.md](./2026-10-27-00-客户端快速接入.md)

## 0. 示例地址

| 地址 | 是谁 |
|---|---|
| `http://localhost:8080` | **AgentAdaptor 网关**：注册工具、`/chat`、`/mcp`、WS 都连它 |
| `ws://localhost:8080/ws/agent` | AgentAdaptor 的 WebSocket 入口 |
| `http://localhost:8082` | **客户端自己的 HTTP 回调服务**，只在 SERVER 模式使用，不是网关 |

本仓库的示例客户端监听 `8082`，所以示例用它；真实客户端换成自己的地址。

## 1. 接入总览

客户端只需要做三件事：

1. 把工具注册给网关；
2. 提供工具执行通道（HTTP 回调或 WebSocket）；
3. 调 `POST /chat` 发起对话。

```text
Client --register_tools--> Gateway
Agent  --MCP tools/call--> Gateway --tool_call--> Client
Client --tool_result-----> Gateway --MCP content--> Agent
Client --POST /chat------> Gateway --final/SSE----> Client
```

客户端不需要实现 MCP；Agent 也不需要知道客户端的存在。

## 2. 注册工具

```http
POST /clients/register
Content-Type: application/json
```

```json
{
  "v": "0.1",
  "id": "reg-1",
  "type": "register_tools",
  "payload": {
    "clientId": "xiaohongshu",
    "clientType": "SERVER",
    "baseCallbackUrl": "https://client.example.com",
    "defaultCallbackPath": "/client/tools/execute",
    "tools": [
      {
        "name": "get_user_profile",
        "description": "获取当前用户资料",
        "inputSchema": {
          "type": "object",
          "properties": {},
          "additionalProperties": false
        }
      }
    ]
  }
}
```

字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `clientId` | 是 | 客户端唯一标识，也是隔离边界 |
| `clientType` | 是 | `SERVER`（HTTP 回调）或 `MOBILE`（WS） |
| `baseCallbackUrl` | SERVER 必填 | **客户端自己的**回调地址，不是 AgentAdaptor 地址 |
| `defaultCallbackPath` | 否 | 工具未指定 `callbackPath` 时使用 |
| `tools[].name` | 是 | 客户端内唯一 |
| `tools[].description` | 是 | 给模型看的用途说明 |
| `tools[].inputSchema` | 是 | 标准 JSON Schema |
| `tools[].callbackPath` | 否 | 工具级回调路径 |

说明：

- 同一 `clientId` 再次注册会**全量替换**工具目录；
- 注册成功返回 `tools_ack`；
- 注册失败返回 `400 + error` 信封。

## 3. 执行工具

### 3.1 SERVER：HTTP 回调

网关会向 `baseCallbackUrl + callbackPath` POST：

```json
{
  "v": "0.1",
  "type": "tool_call",
  "payload": {
    "chatId": "chat-1",
    "callId": "call-1",
    "tool": "get_user_profile",
    "arguments": {},
    "deadlineMs": 30000
  }
}
```

客户端执行后返回：

```json
{
  "v": "0.1",
  "type": "tool_result",
  "payload": {
    "callId": "call-1",
    "status": "success",
    "result": { "name": "张三" }
  }
}
```

失败时：

```json
{
  "v": "0.1",
  "type": "tool_result",
  "payload": {
    "callId": "call-1",
    "status": "error",
    "error": { "message": "用户不存在" }
  }
}
```

### 3.2 MOBILE：WebSocket

注意：**当前工具注册统一走 HTTP，不是在 WS 里注册。** WS 只负责连接绑定和工具调用。

先注册，`clientType` 用 `MOBILE`：

```json
{
  "v": "0.1",
  "id": "reg-1",
  "type": "register_tools",
  "payload": {
    "clientId": "xiaohongshu-app",
    "clientType": "MOBILE",
    "tools": [
      {
        "name": "get_user_profile",
        "description": "获取当前用户资料",
        "inputSchema": {
          "type": "object",
          "properties": {},
          "additionalProperties": false
        }
      }
    ]
  }
}
```

再连接：

```text
ws://<AgentAdaptor>/ws/agent
```

1. 连接后发 `hello`，带 `clientId`、`endUserId`；
2. 收到 `hello_ack` 后保持连接；
3. 收到 `tool_call` 后执行；
4. 在同一条连接回 `tool_result`。

同一 `(clientId, endUserId)` 只保留最后一条连接。

### 3.3 共同约束

- `callId` 必须原样回传；
- 在 `deadlineMs` 内返回结果；
- 工具执行失败用 `status=error`，不要把异常直接抛成 5xx；
- 工具始终在客户端执行，网关不执行工具。

## 4. 发起对话

```http
POST /chat
Content-Type: application/json
Accept: application/json
```

```json
{
  "v": "0.1",
  "id": "req-1",
  "type": "chat",
  "payload": {
    "clientId": "xiaohongshu",
    "endUserId": "u-123",
    "sessionId": null,
    "prompt": "帮我写一篇咖啡测评",
    "agent": "cli"
  }
}
```

返回 `final`：

```json
{
  "v": "0.1",
  "id": "req-1",
  "type": "final",
  "payload": {
    "sessionId": "xiaohongshu:u-123:uuid",
    "chatId": "chat-1",
    "agent": "cli",
    "output": "..."
  }
}
```

- `sessionId` 用于下一轮续聊；
- `endUserId` 用于多用户隔离；
- `agent` 可指定 `self / cli / coze`，不传用默认。

### 流式

把 `Accept` 改为 `text/event-stream`：

```text
event: delta
data: {"v":"0.1","type":"delta","payload":{"chatId":"chat-1","seq":1,"text":"..."}}

event: thinking
data: {"v":"0.1","type":"thinking","payload":{"chatId":"chat-1","seq":2,"text":"..."}}

event: final
data: {"v":"0.1","type":"final","payload":{"sessionId":"...","chatId":"chat-1","agent":"cli","output":"..."}}
```

- `delta`：文本增量；
- `thinking`：思考增量，可能没有；
- `final`：完整结果，以它为准；
- `error`：失败；
- `tool_call` 不在聊天流里，仍走第 3 节的工具通道。

## 5. Java SDK 示例

### 5.1 HTTP 回调

```java
AgentClient client = AgentClient.builder()
        .gateway("http://localhost:8080")        // AgentAdaptor 网关
        .transport(Transport.HTTP_CALLBACK)
        .callbackBaseUrl("http://localhost:8082") // 客户端自己的回调服务
        .clientId("xiaohongshu")
        .endUserId("u-123")
        .tool("get_user_profile", "获取当前用户资料",
              Map.of("type", "object", "additionalProperties", false),
              args -> Map.of("name", "张三"))
        .build();

client.connect();
String finalJson = client.chat("当前用户的姓名是什么", null, null);
```

### 5.2 WebSocket

```java
AgentClient client = AgentClient.builder()
        .gateway("http://localhost:8080")        // AgentAdaptor 网关
        .transport(Transport.WEBSOCKET)
        .wsUrl("ws://localhost:8080/ws/agent")   // AgentAdaptor 的 WS 入口
        .clientId("xiaohongshu-app")
        .endUserId("u-123")
        .tool("get_user_profile", "获取当前用户资料",
              Map.of("type", "object", "additionalProperties", false),
              args -> Map.of("name", "张三"))
        .build();

client.connect();
```

SDK 会自动完成工具注册、`hello`、`tool_call` 分发和 `tool_result` 回传。

### 5.3 流式

```java
ChatStreamResult result = client.chatStream(
        "当前用户的姓名是什么", "cli", null,
        text -> System.out.print(text));
```

## 6. 不使用 SDK 的示例

### 6.1 注册

```bash
# http://localhost:8080 是 AgentAdaptor 网关
curl -X POST http://localhost:8080/clients/register \
  -H "Content-Type: application/json" \
  -d '{
    "v":"0.1","id":"reg-1","type":"register_tools",
    "payload":{
      "clientId":"xiaohongshu-app","clientType":"MOBILE",
      "tools":[{
        "name":"get_user_profile",
        "description":"获取当前用户资料",
        "inputSchema":{"type":"object","properties":{},"additionalProperties":false}
      }]
    }
  }'
```

### 6.2 WebSocket 客户端（Node.js）

```js
import WebSocket from "ws";
import crypto from "node:crypto";

// http://localhost:8080 / ws://localhost:8080 都是 AgentAdaptor 网关
const ws = new WebSocket("ws://localhost:8080/ws/agent");

ws.on("open", () => {
  ws.send(JSON.stringify({
    v: "0.1",
    id: crypto.randomUUID(),
    type: "hello",
    payload: { clientId: "xiaohongshu-app", endUserId: "u-123" }
  }));
});

ws.on("message", async (raw) => {
  const msg = JSON.parse(raw.toString());
  if (msg.type !== "tool_call") return;

  const result = await executeTool(msg.payload.tool, msg.payload.arguments);
  ws.send(JSON.stringify({
    v: "0.1",
    id: msg.payload.callId,
    type: "tool_result",
    payload: {
      callId: msg.payload.callId,
      status: "success",
      result
    }
  }));
});

async function executeTool(name, args) {
  // 在这里执行本地工具
  return { name: "张三" };
}
```

HTTP 回调方式不需要 WS，只需实现一个 POST 端点，返回 `tool_result` 即可，格式见 3.1。

## 7. 常见问题

| 现象 | 排查 |
|---|---|
| 注册 400 | 检查 `clientId`、`clientType`、`tools[].inputSchema` |
| Agent 看不到工具 | 检查 `/mcp/{clientId}` 的 `tools/list` |
| 收不到 `tool_call` | SERVER 检查回调地址/公网可达；MOBILE 检查 WS 是否 `hello` |
| 工具超时 | 检查是否在 `deadlineMs` 内回 `tool_result` |
| 没有流式效果 | 检查 `Accept`，以及 Agent 是否支持流式 |
| 多轮串会话 | 检查 `sessionId` 和 `endUserId` 是否原样回传 |
